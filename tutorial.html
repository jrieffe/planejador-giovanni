🚀 Abrir o Planejador
👤 Para o Giovanni

Como preencher seus horários de estudo

1

Abra o planejador e escolha o dia da semana

Na aba 📅 Agenda Semanal, clique no botão do dia que quer planejar: Segunda, Terça, Quarta etc.

2

Veja os blocos de estudo cinza — são sugestões

Os blocos com fundo cinza claro e o ícone 💡 sugestão já têm uma matéria sugerida. São só sugestões — você pode mudar para o que quiser estudar.

💡 Cinza = Sugestão (ainda não preenchido) ⏳ Amarelo = Sua proposta (aguardando o pai) ✅ Verde = Aprovado pelo pai ❌ Vermelho = Pedir revisão
3

Clique no bloco cinza para editar

Abrirá uma janela. Escolha a matéria no menu e escreva o que vai estudar naquele horário. Por exemplo: "Capítulo 5 de Biologia — genética" ou "Questões de Química do ENEM 2023".

💡 Quanto mais específico você for, mais fácil é pra você mesmo não perder o fio da meada — e pro seu pai entender o que está planejando.
4

Clique em "💾 Propor Horário"

O bloco vai ficar amarelo com o texto "⏳ aguardando validação". Isso significa que a proposta está salva e esperando o ok do seu pai.

5

Repita para todos os dias e envie para o pai

Depois de preencher o que quiser, clique no botão verde 📤 Compartilhar (canto superior direito). Copie o link e mande pelo WhatsApp pro seu pai.

✅ Pronto! O pai vai abrir o link e ver exatamente o que você propôs. Quando ele aprovar, você vai receber um novo link de volta com tudo em verde.
👨 Para o Pai (Jader)

Como validar os horários do Giovanni

1

Abra o link que o Giovanni enviou

Quando o Giovanni clicar em 📤 Compartilhar e mandar o link pelo WhatsApp, abra o link no seu celular ou computador. O plano dele carrega automaticamente.

2

Ative o "Modo Pai" (🔒)

No canto superior direito, clique no botão 🔒 Modo Pai. O botão vai ficar dourado. Agora você consegue aprovar ou rejeitar as propostas.

3

Clique nos blocos amarelos para validar

Cada bloco amarelo é uma proposta do Giovanni. Clique em qualquer um para ver o que ele planejou. Você tem duas opções:

✅ Aprovar — bloco fica verde ❌ Pedir Revisão — bloco fica vermelho
📝 Ao pedir revisão, você pode deixar um comentário para o Giovanni. Ex: "Que tal estudar Biologia aqui em vez de Química? Você tem prova na semana seguinte."
4

Mande o link de volta pro Giovanni

Depois de validar tudo, clique em 📤 Compartilhar e copie o novo link. Mande pelo WhatsApp pro Giovanni. Ele vai abrir e ver o que foi aprovado (verde) e o que precisa revisar (vermelho).

🗓️ Plano Set–Fev

Escolhendo Inglês Presencial e Artes Marciais

1

Abra a aba "🗓️ Plano Set–Fev"

Você vai ver 6 cards, um para cada mês de Setembro/2025 a Fevereiro/2026.

2

Escolha 1 mês para o curso presencial de Inglês / TOEFL

Em cada card do mês tem um botão "Selecionar este mês" para o inglês. Clique no mês que o Giovanni quer fazer as aulas presenciais. Só é possível selecionar um mês no total.

🇺🇸 Dica: escolha um mês com menos compromissos ou mais próximo da data da prova TOEFL.
3

Escolha até 2 meses para Artes Marciais

Em cada card há dois botões: Krav Maga e Aulas com Prof. Iam. Selecione o tipo e o mês. Você pode escolher até 2 meses no total, cada um com um estilo diferente se quiser.

4

Escreva objetivos para cada mês

Cada card tem um campo de texto para "Objetivos do mês". Giovanni pode escrever o que quer focar: provas, conteúdos, metas de estudo. O pai pode revisar e comentar pelo fluxo de compartilhamento.

🌐 Colocar Online

Como deixar o planejador disponível na internet

Para acessar de qualquer celular ou computador — sem precisar ter o arquivo salvo — o melhor é hospedar gratuitamente no GitHub Pages. Siga os passos abaixo. Leva cerca de 10 minutos.

Passo a passo — GitHub Pages (gratuito)

1
Acesse github.com e crie uma conta gratuita (botão "Sign up"). Pode usar o e-mail que já tiver.
2
Após entrar, clique no + (canto superior direito) → "New repository". Dê o nome planejador-giovanni. Marque Public. Clique em "Create repository".
3
Dentro do repositório, clique em "uploading an existing file". Arraste os dois arquivos: index.html e tutorial.html. Clique em "Commit changes".
4
Vá em Settings (engrenagem no topo) → menu lateral Pages → em "Source" escolha Deploy from a branch → Branch: main → pasta: / (root) → clique Save.
5
Aguarde 2 a 3 minutos. O endereço do planejador aparecerá no topo da mesma página Pages, no formato:
https://SEU-USUARIO.github.io/planejador-giovanni/
Mande esse link pro Giovanni pelo WhatsApp e salve nos favoritos!
✅ A partir daí, tanto o Giovanni quanto o Pai acessam o mesmo link de qualquer dispositivo. Não precisa instalar nada.
⚠️ Importante: cada um salva o planejador no próprio navegador (localStorage). Para sincronizar, usem o botão 📤 Compartilhar para trocar links pelo WhatsApp.

Opção mais rápida — Netlify Drop (sem conta)

1
Acesse app.netlify.com/drop no computador.
2
Arraste a pasta com os arquivos index.html e tutorial.html para a área indicada.
3
Em segundos você recebe um link como https://nome-aleatorio.netlify.app. Copie e mande pro Giovanni.
💡 O Netlify Drop é mais rápido, mas o link muda se você redistribuir. Para um link permanente, prefira o GitHub Pages.

❓ Perguntas frequentes

Os dados ficam salvos mesmo se fechar o navegador?

Sim! O planejador salva automaticamente tudo no navegador (localStorage). Da próxima vez que abrir, tudo estará lá — desde que use o mesmo navegador e dispositivo.

O que acontece se o Giovanni abrir o link que o Pai mandou?

O plano validado pelo pai é carregado automaticamente e uma mensagem verde aparece no topo: "✅ Plano recebido do Pai!" O Giovanni vê o que foi aprovado (verde) e o que precisa revisar (vermelho).

Posso usar o planejador sem internet?

Sim, se você já tiver o arquivo salvo no computador ou no celular. Mas para usar o link compartilhado, precisa de internet. Para acessar de qualquer lugar sem guardar o arquivo, use o GitHub Pages.

Posso mudar uma proposta que já foi aprovada?

Em Modo Giovanni, blocos aprovados ficam bloqueados (não clicáveis) para manter o compromisso. Se precisar mudar, o pai pode rejeitar o bloco em Modo Pai, e o Giovanni propõe novamente.

O link compartilhado expira?

Não! O link contém o estado completo do planejador embutido na URL. Ele funciona para sempre. Mas cada vez que o plano muda, você gera um novo link com 📤 Compartilhar.
