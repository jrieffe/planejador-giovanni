Configurar Sincronização

Para que Giovanni e o Pai vejam o mesmo planejador em tempo real, conecte ao Firebase (gratuito). Leva 5 minutos.

Acesse firebase.google.com com conta Google → "Criar um projeto" → qualquer nome → Criar projeto.
Menu lateral: Realtime Database → Criar banco de dados → "Iniciar no modo de teste" → Ativar.
Copie o link do banco: https://nome-default-rtdb.firebaseio.com
Cole abaixo e clique em Conectar. Pronto — ambos compartilham o mesmo planejador!
